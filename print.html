Binding

The bound edge keeps an extra ¾ inch so the hole punch can't reach anything. One-sided puts that margin on the left of every sheet; double-sided mirrors it, so it stays on the inside once the stack is punched.

In Chrome's print box: Destination → Save as PDF (or your printer), Paper size matching the choice above, Margins → Default, Scale → Default (100%), and tick Background graphics so the rules and captions come through. Tick Headers and footers if you want page numbers on each sheet.

The photo files themselves

The printout is the scrapbook; this is the raw material. Every frame lives in a folder under photos/ in this repository.
